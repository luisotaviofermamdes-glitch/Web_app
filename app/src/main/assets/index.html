PC virtual Windows 10

O Web_app agora tem a camada de armazenamento e compartilhamento preparada para uma VM real.

Verificando componentes...
1. ISO do Windows

Escolha a ISO oficial que você já possui no celular. Ela será copiada para o armazenamento privado do Web_app.

2. Disco virtual

Crie um disco esparso para instalar o Windows. 32 GB é o mínimo prático para esta configuração.

3. Arquivos do celular ↔ Windows

Use esta pasta compartilhada para levar Downloads, APKs, ZIPs, documentos e outros arquivos para dentro da VM.

4. VM

A VM precisa do motor QEMU x86_64 Android. O projeto já possui a ponte para iniciar o motor e expor a pasta compartilhada; o binário nativo ainda precisa ser empacotado.
